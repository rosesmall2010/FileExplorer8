FileExplorer8 does not collect, transmit, or share any user data. No accounts, no analytics, no ad SDK, no crash reporting. Everything you see in the app stays on your own machine.

1. What we do not collect

None of the following is collected — not a single item:

  • Your files and folders (contents, names, sizes, modification dates)
  • Your browsing history, search history, clipboard contents
  • Server addresses, accounts, passwords and private keys you connect to
  • Device identifiers (serial number, hardware UUID, advertising identifier)
  • Usage statistics, crash logs, performance data
  • Your location, contacts, calendar, photo library, microphone, camera, screen contents

There is no network request in the app for reporting data. Apart from SSH/SFTP connections you start yourself, the app sends no bytes to any server.

2. Where data lives

All settings and credentials exist only on this Mac, in three places:

LocationWhat it holdsProtection
App sandbox container
~/Library/Containers/com.donghuazhu.FileExplorer8/		Preferences, session state (window position, pane paths), fast-access bookmarksInside the App Sandbox container, reachable only by this app
Same, servers.jsonSSH server endpoints (host, port, username, display name)AES-256-GCM (swift-crypto)
System KeychainSSH passwords and private-key passphrasesProtected by the macOS Keychain

Passwords never go into a file. servers.json holds endpoints only, no secrets. Passwords and passphrases live in the Keychain and are deleted along with their connection.

To be clear: the servers.json encryption key ships with the app (compiled into the binary — it is neither written to disk separately nor stored in the Keychain). That encryption only stops endpoints from being casually read; it is not protection against a local attacker, since anyone who can read your disk can read the app binary too. The things that genuinely need secrecy — passwords and passphrases — live only in the Keychain.

Your private-key files stay exactly where you put them. The app stores a file bookmark for reading only; it never copies or moves them.

3. Network access

The app has exactly one network capability: an SSH / SFTP client.

  • A connection is made only after you add a server and click connect, and it targets the address you entered
  • It is used to browse and transfer files over SSH (the SFTP subsystem)
  • Host keys are verified known_hosts-style; a changed fingerprint asks you to confirm
  • Transferred data is encrypted by SSH itself (OpenSSL as embedded in libssh2)

We operate no servers, and there is no relay or cloud sync service. Your files never pass through us.

The app does not check for updates, load remote ads, or call any third-party API.

4. System permissions

The app runs in the App Sandbox and only reads or writes within what you grant:

PermissionPurposeWhen it appears
User-selected filesBrowse and act on folders you chooseSystem prompt on first entry into a folder outside the sandbox
Downloads / Documents / Music / Pictures / MoviesAccess these standard locations without promptsAvailable right after install
Network access (outbound)Connect to SSH servers you addOnly when you click connect

The table matches the sandbox entitlements in the app bundle one-to-one (app-sandbox, files.user-selected, files.downloads, assets.music / assets.pictures / assets.movies, network.client). Nothing extra is requested.

The app does not request: contacts, calendar, reminders, photo library, camera, microphone, screen recording, full disk access, or accessibility. If you see FileExplorer8 listed under any of those in System Settings › Privacy & Security, it did not come from this app.

You can revoke any granted folder at any time in System Settings › Privacy & Security › Files and Folders.

5. Checksums

The app can compute checksums (SHA-256 / SHA-512 / SHA-1 / MD5 / BLAKE3 / CRC32 / CRC64) so you can verify file integrity.

This feature reads only the files you explicitly select, computes the digest in memory and shows it to you. Nothing is saved, nothing is uploaded. Digests never leave your machine and never reach a log.

6. Deleting your data

We hold no data about you, so there is no “request deletion from us” process — and no account to close, because the app has no accounts.

8. Children's privacy

This app does not collect information from children, or from anyone. The App Store age rating is 4+.

9. Policy changes

If this policy changes, the “Last updated” date at the top of the page is revised and the change ships with a new release. Since the app collects no data, substantive changes are unlikely.
