FileExplorer8은 사용자 데이터를 수집, 전송, 공유하지 않습니다. 계정도, 통계도, 광고 SDK도, 충돌 보고도 없습니다. 앱에서 다루는 모든 파일은 사용자의 Mac에만 남습니다.

1. 수집하지 않는 것

다음 데이터는 하나도 수집하지 않습니다:

  • 파일과 폴더(내용, 이름, 크기, 수정 시각)
  • 방문 기록, 검색 기록, 클립보드 내용
  • 연결하는 서버 주소, 계정, 비밀번호, 개인 키
  • 기기 식별자(일련번호, 하드웨어 UUID, 광고 식별자)
  • 사용 통계, 충돌 로그, 성능 데이터
  • 위치, 연락처, 캘린더, 사진 보관함, 마이크, 카메라, 화면 내용

데이터를 보내는 네트워크 요청은 앱 안에 전혀 없습니다. 직접 시작한 SSH/SFTP 연결을 제외하면 앱은 어떤 서버로도 단 1바이트도 보내지 않습니다.

2. 데이터가 있는 곳

설정과 자격 증명은 모두 이 Mac 안에만 세 곳으로 나뉘어 있습니다:

위치저장 내용보호 방식
앱 샌드박스 컨테이너
~/Library/Containers/com.donghuazhu.FileExplorer8/		환경설정, 세션 상태(창 위치, 각 패널 경로 등), 빠른 접근 북마크App Sandbox 컨테이너 안이며 이 앱만 접근 가능

비밀번호는 파일에 들어가지 않습니다. servers.json에는 엔드포인트 정보만 있고 비밀은 없습니다. 비밀번호와 개인 키 암호는 시스템 키체인에 저장되며 연결을 삭제하면 함께 삭제됩니다.

분명히 밝혀 둡니다. servers.json의 암호화 키는 앱과 함께 배포됩니다(바이너리에 컴파일되어 있으며, 별도 파일로도 키체인에도 저장되지 않습니다). 이 암호화는 엔드포인트 정보를 쉽게 들여다보지 못하게 하는 수준이며, 로컬 공격자에 대한 보호는 아닙니다. 디스크를 읽을 수 있는 사람은 앱 본체도 읽을 수 있기 때문입니다. 정말로 감춰야 하는 것(비밀번호, 암호)은 언제나 키체인에만 있습니다.

개인 키 파일 자체는 사용자가 둔 위치에 그대로 남습니다. 앱은 읽기용 파일 북마크만 저장하고 복사하거나 옮기지 않습니다.

3. 네트워크 접근

앱의 네트워크 기능은 SSH / SFTP 클라이언트 하나뿐입니다.

  • 직접 서버를 추가하고 연결을 클릭할 때만 연결하며 대상은 사용자가 입력한 주소입니다
  • 용도는 파일 탐색과 전송이며 프로토콜은 SSH(SFTP 서브시스템)입니다
  • 호스트 키는 known_hosts 방식으로 검증하고 지문이 바뀌면 확인을 요청합니다
  • 전송 내용은 SSH 자체의 암호화(libssh2에 내장된 OpenSSL)로 보호됩니다

당사는 어떤 서버도 운영하지 않습니다. 중계나 클라우드 동기화 서비스도 없습니다. 사용자의 파일은 당사를 거치지 않습니다.

앱은 업데이트를 확인하지 않고, 원격 광고를 불러오지 않으며, 어떤 타사 API도 호출하지 않습니다.

4. 시스템 권한

앱은 App Sandbox를 켜고 사용자가 허용한 범위에서만 파일을 읽고 씁니다:

권한용도표시 시점
사용자가 선택한 파일지정한 폴더 탐색과 조작샌드박스 밖 폴더에 처음 들어갈 때 시스템이 확인
다운로드 / 문서 / 음악 / 사진 / 동영상 폴더확인 없이 이 표준 위치에 접근설치 직후부터 사용 가능
네트워크 접근(외부)사용자가 추가한 SSH 서버 연결연결을 클릭할 때만

위 표는 앱 번들의 실제 샌드박스 권한과 하나씩 대응합니다(app-sandbox, files.user-selected, files.downloads, assets.music / assets.pictures / assets.movies, network.client). 더 요청한 항목은 없습니다.

앱은 다음을 요청하지 않습니다: 연락처, 캘린더, 미리 알림, 사진 보관함, 카메라, 마이크, 화면 기록, 전체 디스크 접근, 손쉬운 사용. 시스템 설정 › 개인정보 보호 및 보안의 해당 항목에 FileExplorer8이 보여도 이 앱이 요청한 것이 아닙니다.

허용한 폴더는 시스템 설정 › 개인정보 보호 및 보안 › 파일 및 폴더에서 언제든지 취소할 수 있습니다.

5. 체크섬 기능

앱은 파일 무결성 확인을 위해 체크섬(SHA-256 / SHA-512 / SHA-1 / MD5 / BLAKE3 / CRC32 / CRC64)을 계산할 수 있습니다.

이 기능은 명시적으로 선택한 파일만 읽고 메모리에서 다이제스트를 계산해 보여 줍니다. 저장하지도 전송하지도 않습니다. 다이제스트는 Mac 밖으로 나가지 않고 로그에도 남지 않습니다.

6. 데이터 삭제

삭제할 대상방법
특정 SSH 연결의 비밀번호앱에서 해당 연결을 삭제하면 키체인의 비밀번호와 암호도 삭제됩니다
모든 환경설정과 세션앱의 “재설정” 기능을 쓰거나 ~/Library/Containers/com.donghuazhu.FileExplorer8/ 삭제
모든 데이터앱을 제거한 뒤 위 폴더 삭제

당사는 사용자에 대한 어떤 데이터도 가지고 있지 않으므로 “당사에 삭제를 요청하는” 절차가 없습니다. 계정도 없으므로 탈퇴도 필요 없습니다.

7. 서드파티 구성 요소

앱에 포함된 오픈소스 의존성은 두 개뿐입니다:

구성 요소용도설명
SwiftSFTPSSH / SFTP 프로토콜 구현libssh2와 OpenSSL 소스를 포함하며 완전히 로컬에서 동작합니다. 통계나 전송 코드는 없습니다
swift-crypto암호 기본 요소(Apple 제공)AES-256-GCM, SHA-2, HMAC 등 표준 알고리즘. 로컬 설정 암호화, SSH 호스트 지문 검증, 체크섬 계산에 사용하며 모두 로컬 연산이고 네트워크를 쓰지 않습니다

앱 안에 광고 SDK, 통계 SDK, 충돌 수집 SDK, 소셜 로그인 SDK는 없습니다.

8. 아동 개인정보

이 앱은 아동에게서도 누구에게서도 정보를 수집하지 않습니다. App Store 연령 등급은 4+입니다.

9. 방침 변경

이 방침을 고치면 페이지 위쪽의 “최종 수정” 날짜를 갱신하고 새 버전과 함께 배포합니다. 데이터를 수집하지 않으므로 실질적인 변경 가능성은 낮습니다.

English summary (for App Review reference)

FileExplorer8 does not collect, transmit, or share any user data.

  • No analytics, no ads, no crash reporting, no accounts.
  • All settings and credentials stay on the user's Mac. Passwords live in the macOS Keychain; server endpoints in a local file encrypted with AES-256-GCM (the key ships inside the app, so this obfuscates endpoints rather than protecting against local attackers).
  • The only network capability is an SSH/SFTP client that connects only to servers the user adds. We operate no servers and receive nothing.
  • The app runs in the App Sandbox and requests only user-selected file access, standard folders (Downloads / Documents / Music / Pictures / Movies), and outbound network access.
  • Two open-source dependencies: SwiftSFTP (embedded libssh2 + OpenSSL) and Apple's swift-crypto; both run fully locally with no telemetry.
