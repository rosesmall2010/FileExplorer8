FileExplorer8 erhebt, überträgt und teilt keine Benutzerdaten. Keine Konten, keine Analyse, kein Werbe-SDK, keine Absturzberichte. Alles, was Sie in der App sehen, bleibt auf Ihrem Mac.

1. Was wir nicht erheben

Nichts davon wird erhoben – nicht ein einziger Punkt:

  • Ihre Dateien und Ordner (Inhalte, Namen, Größen, Änderungsdaten)
  • Ihr Verlauf, Ihre Suchanfragen, Zwischenablageinhalte
  • Serveradressen, Konten, Passwörter und private Schlüssel, zu denen Sie sich verbinden
  • Gerätekennungen (Seriennummer, Hardware-UUID, Werbe-ID)
  • Nutzungsstatistiken, Absturzprotokolle, Leistungsdaten
  • Ihren Standort, Kontakte, Kalender, Fotomediathek, Mikrofon, Kamera, Bildschirminhalt

Es gibt keine Netzwerkanfrage in der App, die Daten meldet. Außer von Ihnen gestarteten SSH/SFTP-Verbindungen sendet die App kein Byte an einen Server.

2. Wo Daten liegen

Alle Einstellungen und Zugangsdaten existieren nur auf diesem Mac, an drei Orten:

Passwörter landen nie in einer Datei. servers.json enthält nur Endpunkte, keine Geheimnisse. Passwörter und Passphrasen liegen im Schlüsselbund und werden mit ihrer Verbindung gelöscht.

Zur Klarstellung: Der Schlüssel für die servers.json-Verschlüsselung wird mit der App ausgeliefert (in die Binärdatei kompiliert – weder separat auf der Platte noch im Schlüsselbund). Diese Verschlüsselung verhindert nur flüchtiges Mitlesen der Endpunkte; sie ist kein Schutz gegen einen lokalen Angreifer, denn wer Ihre Platte lesen kann, kann auch die App selbst lesen. Was wirklich geheim bleiben muss – Passwörter und Passphrasen – liegt ausschließlich im Schlüsselbund.

Ihre Dateien mit privaten Schlüsseln bleiben genau dort, wo Sie sie ablegen. Die App speichert nur ein Datei-Lesezeichen zum Lesen; sie kopiert oder verschiebt sie nie.

3. Netzwerkzugriff

Die App hat genau eine Netzwerkfähigkeit: einen SSH/SFTP-Client.

  • Eine Verbindung entsteht erst, wenn Sie einen Server hinzufügen und auf Verbinden klicken – Ziel ist die von Ihnen eingegebene Adresse
  • Sie dient dem Durchsuchen und Übertragen von Dateien über SSH (SFTP-Subsystem)
  • Host-Schlüssel werden known_hosts-konform geprüft; ein geänderter Fingerabdruck verlangt Ihre Bestätigung
  • Übertragene Daten verschlüsselt SSH selbst (OpenSSL, wie in libssh2 eingebettet)

Wir betreiben keine Server, es gibt keinen Relay- und keinen Cloud-Synchronisierungsdienst. Ihre Dateien laufen nie über uns.

Die App prüft keine Updates, lädt keine Werbung aus dem Netz und ruft keine Schnittstellen Dritter auf.

5. Prüfsummen

Die App berechnet Prüfsummen (SHA-256 / SHA-512 / SHA-1 / MD5 / BLAKE3 / CRC32 / CRC64), damit Sie die Integrität von Dateien prüfen können.

Diese Funktion liest nur die von Ihnen ausdrücklich gewählten Dateien, berechnet den Hash im Speicher und zeigt ihn an. Nichts wird gespeichert oder hochgeladen. Hashes verlassen Ihren Mac nie und landen in keinem Protokoll.

English summary (for App Review reference)

FileExplorer8 does not collect, transmit, or share any user data.

  • No analytics, no ads, no crash reporting, no accounts.
  • All settings and credentials stay on the user's Mac. Passwords live in the macOS Keychain; server endpoints in a local file encrypted with AES-256-GCM (the key ships inside the app, so this obfuscates endpoints rather than protecting against local attackers).
  • The only network capability is an SSH/SFTP client that connects only to servers the user adds. We operate no servers and receive nothing.
  • The app runs in the App Sandbox and requests only user-selected file access, standard folders (Downloads / Documents / Music / Pictures / Movies), and outbound network access.
  • Two open-source dependencies: SwiftSFTP (embedded libssh2 + OpenSSL) and Apple's swift-crypto; both run fully locally with no telemetry.
