支援

遇到問題、想提建議、或發現 bug？

請到 GitHub Issues 提交，附上你的 macOS 版本、文件8 版本號，以及能重現問題的步驟。能附截圖更好。

版本號在「文件8 › 關於文件8」裡可以看到。

常見問題

為什麼進入某些目錄會彈窗要求授權？
應用程式開啟了 App Sandbox。桌面、下載、文件、外接磁碟等位置在沙盒之外，首次進入某個目錄時 macOS 會強制彈窗詢問，這是系統的安全設計，不是缺陷。選擇「授權此資料夾」後，該目錄會被記住，同一路徑一次執行只問一次。

會不會讀取我的通訊錄、相機或螢幕？
不會。文件8 只申請了使用者選擇的檔案存取、標準資料夾（下載 / 文件 / 音樂 / 圖片 / 影片）與對外網路存取，沒有通訊錄、相機、麥克風、螢幕錄製或完全磁碟存取權限。

SSH 密碼存在哪裡？
存在 macOS 系統鑰匙圈裡。伺服器端點資訊存在本機沙盒容器內（AES-256-GCM 加密）。密碼可以不儲存，改為每次連線時彈出一次性登入框。詳見隱私政策。

支援 Apple Silicon 和 Intel 嗎？
兩者都支援，安裝包是通用二進位。系統要求 macOS 15.0 或更高版本。

解除安裝後殘留資料怎麼清理？
刪除應用程式後，再刪除 ~/Library/Containers/com.donghuazhu.FileExplorer8/ 即可清空偏好、工作階段記錄與伺服器端點資訊（沙盒應用程式的資料都在你自己的容器裡，不在系統共用位置）。SSH 密碼存在系統鑰匙圈，刪除對應連線時會一併刪除。

功能

文件8 把三種互動範式裝進同一個視窗，按 ⇧⌘D 一步循環切換，三種形態各自儲存現場（路徑、標籤、排序、欄寬、選取項目）。

  • 檔案管理器: 探索與整理。側邊欄目錄樹、位址列、完整標籤頁、六種檢視佈局。
  • 雙欄管理器: 來源 / 目標範式，九個操作列按鈕，批次搬移。
  • 四欄管理器: 田字 2×2，同時看四個目錄，多目標分流。
  • 寫入操作先預檢: 複製、搬移、覆蓋前先給 dry-run 結論，這一步不寫任何位元組。
  • 三級復原: 同卷宗搬移、重新命名、刪除到垃圾桶、打包解壓 ZIP 保證可復原。
  • 預覽: Space 快速預覽，原始碼帶語法著色，PDF 走 PDFKit，SSH 遠端檔案 10 MB 內也能看。
  • SSH 遠端目錄: 用密碼或私鑰連伺服器，遠端目錄和本機一樣操作。
  • 14 種語言: 簡中、繁中、英、日、韓、德、法、西、巴西葡、俄、越、印尼、馬來、泰。
