文件8 不蒐集、不上傳、不分享任何使用者資料。沒有帳號系統，沒有統計分析，沒有廣告 SDK，沒有當機回報。你在應用程式裡看到的一切檔案都留在你自己的機器上。

一、我們不蒐集什麼

以下資料一項都不蒐集：

  • 你的檔案與資料夾（內容、名稱、大小、修改時間）
  • 你的瀏覽歷史、搜尋記錄、剪貼簿內容
  • 你連線的伺服器位址、帳號、密碼、私鑰
  • 裝置識別碼（序號、硬體 UUID、廣告識別碼）
  • 使用統計、當機記錄、效能資料
  • 你的位置、通訊錄、行事曆、相簿、麥克風、相機、螢幕內容

應用程式內沒有任何用於資料回報的網路請求。除你主動發起的 SSH/SFTP 連線外，應用程式不會向任何伺服器傳送任何位元組。

二、資料存在哪裡

所有設定與憑證都只存在於這台 Mac 上，分三處：

位置存什麼保護方式
應用程式沙盒容器
~/Library/Containers/com.donghuazhu.FileExplorer8/		偏好設定、工作階段現場（視窗位置、各欄路徑等）、快速存取書籤App Sandbox 容器內，僅本應用程式可存取
同上，servers.jsonSSH 伺服器端點（主機、連接埠、使用者名稱、顯示名稱）AES-256-GCM 加密（swift-crypto）
系統鑰匙圈（Keychain）SSH 密碼、私鑰通行碼由 macOS 鑰匙圈保護

密碼與通行碼不進檔案。 servers.json 裡只有端點資訊，沒有秘密；密碼與私鑰通行碼存在系統鑰匙圈，刪除某條連線時一併刪除。

需要說明的是，servers.json 的加密金鑰隨應用程式一同散佈（編譯進程式內，不單獨落盤、也不在鑰匙圈裡）。這道加密只是防止端點資訊被隨意翻看，不構成針對本機攻擊者的保護——能讀你磁碟的人也能讀應用程式本體。真正需要保密的內容（密碼、通行碼）始終只在鑰匙圈裡。

私鑰檔案本身永遠留在你自己放的位置，應用程式只儲存一個檔案書籤用於讀取，不複製、不搬移到別處。

三、網路存取

應用程式只有一個網路能力：SSH / SFTP 用戶端。

  • 只在你主動新增伺服器並點擊連線時才發起連線，目標是你自己填的位址
  • 連線用途是瀏覽與傳輸檔案，協定為 SSH（SFTP 子系統）
  • 主機金鑰按 known_hosts 方式驗證，指紋變化會提示你確認
  • 傳輸內容經過 SSH 協定本身的加密（libssh2 內建 OpenSSL 實作）

我們不營運任何伺服器，也沒有任何中轉或雲端同步服務。你的檔案不經過我們。

應用程式不檢查更新、不載入遠端廣告、不請求任何第三方介面。

四、系統權限

應用程式開啟 App Sandbox，只在你授予的範圍內讀寫檔案：

權限用途何時出現
使用者選擇的檔案瀏覽與操作你指定的目錄首次進入沙盒外的目錄時由系統彈窗
下載 / 文件 / 音樂 / 圖片 / 影片資料夾免彈窗直接存取這幾個標準位置安裝後即可用
網路存取（對外）連線你自己新增的 SSH 伺服器僅在你點擊連線時

上表與應用程式套件內實際的沙盒權限一一對應（app-sandbox、files.user-selected、files.downloads、assets.music / assets.pictures / assets.movies、network.client），沒有多申請任何一項。

應用程式不申請：通訊錄、行事曆、提醒事項、照片圖庫、相機、麥克風、螢幕錄製、完全磁碟存取、輔助使用。若你在「系統設定 › 隱私權與安全性」裡看到這些項目下有「文件8」，那不是本應用程式申請的。

你也可以隨時在「系統設定 › 隱私權與安全性 › 檔案和資料夾」裡撤銷已授予的目錄。

五、檔案校驗和功能

應用程式提供「計算校驗和」（SHA-256 / SHA-512 / SHA-1 / MD5 / BLAKE3 / CRC32 / CRC64），用於核對檔案完整性。

這項功能只讀取你明確選取的檔案，在記憶體中計算摘要並顯示給你，不儲存、不上傳。摘要值不會離開你的機器，也不會進入任何記錄。

六、刪除你的資料

想刪什麼怎麼做
某條 SSH 連線的密碼應用程式內刪除該連線，鑰匙圈裡的密碼與通行碼隨之刪除
全部偏好與工作階段應用程式內「重置」功能，或刪除 ~/Library/Containers/com.donghuazhu.FileExplorer8/
全部資料解除安裝應用程式，再刪除上面那個目錄

我們這邊沒有你的任何資料，因此不存在「向我們申請刪除」的流程——也無需註銷帳號，本應用程式沒有帳號。

七、第三方元件

應用程式只包含兩個開源相依項目：

元件用途說明
SwiftSFTPSSH / SFTP 協定實作內嵌 libssh2 與 OpenSSL 原始碼，純本機執行，不含任何統計或聯網回報程式碼
swift-crypto加密原語（Apple 官方）AES-256-GCM、SHA-2、HMAC 等標準演算法；用於本機設定加密、SSH 主機指紋驗證與檔案校驗和計算，純本機運算，不聯網

應用程式內沒有廣告 SDK、統計分析 SDK、當機蒐集 SDK、社交登入 SDK。

八、兒童隱私

本應用程式不針對兒童蒐集任何資訊，也不蒐集任何人的資訊。App Store 年齡分級為 4+。

九、政策變更

本政策如有修改，會更新本頁頂端的「最後更新」日期，並隨新版本發佈。由於本應用程式不蒐集資料，實質變更的可能性很低。

English summary (for App Review reference)

FileExplorer8 does not collect, transmit, or share any user data.

  • No analytics, no ads, no crash reporting, no accounts.
  • All settings and credentials stay on the user's Mac. Passwords live in the macOS Keychain; server endpoints in a local file encrypted with AES-256-GCM (the key ships inside the app, so this obfuscates endpoints rather than protecting against local attackers).
  • The only network capability is an SSH/SFTP client that connects only to servers the user adds. We operate no servers and receive nothing.
  • The app runs in the App Sandbox and requests only user-selected file access, standard folders (Downloads / Documents / Music / Pictures / Movies), and outbound network access.
  • Two open-source dependencies: SwiftSFTP (embedded libssh2 + OpenSSL) and Apple's swift-crypto; both run fully locally with no telemetry.
