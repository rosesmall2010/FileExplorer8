FileExplorer8 ไม่เก็บรวบรวม ไม่ส่ง และไม่แบ่งปันข้อมูลผู้ใช้ใด ๆ ไม่มีบัญชี ไม่มีการวิเคราะห์ ไม่มี SDK โฆษณา ไม่มีการรายงานแอปขัดข้อง ทุกสิ่งที่คุณเห็นในแอปจะอยู่บน Mac ของคุณเอง

1. สิ่งที่เราไม่เก็บรวบรวม

ไม่มีข้อมูลใดต่อไปนี้ที่ถูกเก็บรวบรวม แม้แต่รายการเดียว:

  • ไฟล์และโฟลเดอร์ของคุณ (เนื้อหา ชื่อ ขนาด เวลาแก้ไข)
  • ประวัติการเรียกดูและการค้นหา เนื้อหาในคลิปบอร์ด
  • ที่อยู่เซิร์ฟเวอร์ บัญชี รหัสผ่าน และคีย์ส่วนตัวที่คุณเชื่อมต่อ
  • ตัวระบุอุปกรณ์ (หมายเลขซีเรียล UUID ของฮาร์ดแวร์ ตัวระบุโฆษณา)
  • สถิติการใช้งาน บันทึกแอปขัดข้อง ข้อมูลประสิทธิภาพ
  • ตำแหน่งที่ตั้ง รายชื่อผู้ติดต่อ ปฏิทิน คลังภาพ ไมโครโฟน กล้อง และเนื้อหาหน้าจอของคุณ

ไม่มีคำขอเครือข่ายใด ๆ ในแอปที่ใช้ส่งข้อมูล นอกจากเซสชัน SSH/SFTP ที่คุณเริ่มเอง แอปไม่ส่งแม้แต่ไบต์เดียวไปยังเซิร์ฟเวอร์ใด

2. ข้อมูลอยู่ที่ไหน

การตั้งค่าและข้อมูลรับรองทั้งหมดมีอยู่เฉพาะบน Mac เครื่องนี้ ในสามที่:

ตำแหน่งเก็บอะไรการป้องกัน
คอนเทนเนอร์ sandbox ของแอป
~/Library/Containers/com.donghuazhu.FileExplorer8/		การตั้งค่า สถานะเซสชัน (ตำแหน่งหน้าต่าง เส้นทางของแต่ละบาน) บุ๊กมาร์กเข้าถึงเร็วภายในคอนเทนเนอร์ App Sandbox เข้าถึงได้เฉพาะแอปนี้
ที่เดียวกัน servers.jsonปลายทางการเชื่อมต่อเซิร์ฟเวอร์ SSH (โฮสต์ พอร์ต ชื่อผู้ใช้ ชื่อที่แสดง)เข้ารหัส AES-256-GCM (swift-crypto)
พวงกุญแจของระบบรหัสผ่าน SSH และวลีรหัสผ่านของคีย์ส่วนตัวได้รับการคุ้มครองโดยพวงกุญแจ macOS

รหัสผ่านไม่เคยลงในไฟล์ servers.json มีเพียงข้อมูลปลายทาง ไม่มีความลับ รหัสผ่านและวลีรหัสผ่านอยู่ในพวงกุญแจ และจะถูกลบไปพร้อมกับการเชื่อมต่อนั้น

ขอชี้แจงให้ชัด: กุญแจเข้ารหัสของ servers.json ถูกแจกจ่ายไปพร้อมแอป (คอมไพล์เข้าไปในไบนารี ไม่ได้เขียนแยกไว้บนดิสก์ และไม่ได้อยู่ในพวงกุญแจ) การเข้ารหัสชั้นนี้เพียงป้องกันไม่ให้ข้อมูลปลายทางถูกเปิดดูโดยพลการ ไม่ถือเป็นการป้องกันจากผู้โจมตีในเครื่อง เพราะผู้ที่อ่านดิสก์ของคุณได้ก็อ่านไบนารีของแอปได้เช่นกัน สิ่งที่ต้องเก็บเป็นความลับจริง ๆ (รหัสผ่านและวลีรหัสผ่าน) อยู่ในพวงกุญแจเท่านั้น

ไฟล์คีย์ส่วนตัวของคุณ ยังอยู่ที่ที่คุณวางไว้ แอปเพียงบันทึกบุ๊กมาร์กสำหรับอ่าน ไม่คัดลอกหรือย้ายไปที่อื่น

3. การเข้าถึงเครือข่าย

แอปมีความสามารถด้านเครือข่ายเพียงอย่างเดียว: ไคลเอนต์ SSH / SFTP

  • จะเชื่อมต่อก็ต่อเมื่อคุณเพิ่มเซิร์ฟเวอร์และกดเชื่อมต่อ โดยไปยังที่อยู่ที่คุณกรอกเอง
  • ใช้สำหรับเรียกดูและถ่ายโอนไฟล์ผ่าน SSH (ระบบย่อย SFTP)
  • ตรวจสอบคีย์โฮสต์แบบ known_hosts หากลายนิ้วมือเปลี่ยนจะขอให้คุณยืนยัน
  • ข้อมูลที่ถ่ายโอนได้รับการเข้ารหัสโดย SSH เอง (OpenSSL ตามที่ฝังใน libssh2)

เราไม่ได้ให้บริการเซิร์ฟเวอร์ใด ๆ ไม่มีตัวกลางหรือบริการซิงก์บนคลาวด์ ไฟล์ของคุณไม่เคยผ่านเรา

แอปไม่ตรวจสอบอัปเดต ไม่โหลดโฆษณาระยะไกล และไม่เรียก API ของบุคคลที่สาม

4. สิทธิ์ของระบบ

แอปทำงานใน App Sandbox และอ่านหรือเขียนเฉพาะในขอบเขตที่คุณอนุญาต:

สิทธิ์วัตถุประสงค์ปรากฏเมื่อใด
ไฟล์ที่ผู้ใช้เลือกเรียกดูและดำเนินการกับโฟลเดอร์ที่คุณระบุระบบถามเมื่อเข้าสู่โฟลเดอร์นอก sandbox ครั้งแรก
โฟลเดอร์ดาวน์โหลด / เอกสาร / เพลง / รูปภาพ / ภาพยนตร์เข้าถึงตำแหน่งมาตรฐานเหล่านี้โดยไม่ต้องถามใช้ได้ทันทีหลังติดตั้ง
การเข้าถึงเครือข่าย (ขาออก)เชื่อมต่อกับเซิร์ฟเวอร์ SSH ที่คุณเพิ่มเฉพาะเมื่อคุณกดเชื่อมต่อ

ตารางข้างต้นตรงกับสิทธิ์ sandbox ในแพ็กเกจแอปแบบหนึ่งต่อหนึ่ง (app-sandbox, files.user-selected, files.downloads, assets.music / assets.pictures / assets.movies, network.client) ไม่ได้ขอเพิ่มเติมใด ๆ

แอปไม่ขอสิทธิ์: รายชื่อผู้ติดต่อ ปฏิทิน การเตือน คลังภาพ กล้อง ไมโครโฟน การบันทึกหน้าจอ การเข้าถึงดิสก์ทั้งหมด หรือการช่วยการเข้าถึง หากคุณเห็น FileExplorer8 ในรายการเหล่านั้นที่ การตั้งค่าระบบ › ความเป็นส่วนตัวและความปลอดภัย นั่นไม่ใช่คำขอจากแอปนี้

คุณสามารถเพิกถอนโฟลเดอร์ที่อนุญาตได้ทุกเมื่อที่ การตั้งค่าระบบ › ความเป็นส่วนตัวและความปลอดภัย › ไฟล์และโฟลเดอร์

5. การคำนวณเช็กซัม

แอปคำนวณเช็กซัมได้ (SHA-256 / SHA-512 / SHA-1 / MD5 / BLAKE3 / CRC32 / CRC64) เพื่อตรวจสอบความสมบูรณ์ของไฟล์

ฟังก์ชันนี้อ่านเฉพาะไฟล์ที่คุณเลือกอย่างชัดเจน คำนวณค่าแฮชในหน่วยความจำและแสดงให้คุณดู ไม่บันทึก ไม่ส่งออก ค่าแฮชไม่ออกจากเครื่องของคุณและไม่ลงในบันทึกใด ๆ

6. การลบข้อมูลของคุณ

สิ่งที่ต้องการลบวิธีทำ
รหัสผ่านของการเชื่อมต่อ SSH หนึ่งรายการลบการเชื่อมต่อนั้นในแอป รหัสผ่านและวลีรหัสผ่านในพวงกุญแจจะถูกลบไปด้วย
การตั้งค่าและเซสชันทั้งหมดใช้รีเซ็ตในแอป หรือลบ ~/Library/Containers/com.donghuazhu.FileExplorer8/
ข้อมูลทั้งหมดถอนการติดตั้งแอป แล้วลบโฟลเดอร์ข้างต้น

เราไม่มีข้อมูลใด ๆ ของคุณ จึงไม่มีขั้นตอน “ขอลบข้อมูลจากเรา” และไม่มีบัญชีให้ปิด เพราะแอปนี้ไม่มีบัญชี

7. คอมโพเนนต์ของบุคคลที่สาม

แอปมี Dependency โอเพนซอร์สเพียงสองรายการ:

คอมโพเนนต์วัตถุประสงค์หมายเหตุ
SwiftSFTPการทำงานของโปรโตคอล SSH / SFTPฝังซอร์สของ libssh2 และ OpenSSL ทำงานในเครื่องทั้งหมด ไม่มีโค้ดวิเคราะห์หรือส่งข้อมูล
swift-cryptoพื้นฐานการเข้ารหัส (จาก Apple)AES-256-GCM, SHA-2, HMAC และอัลกอริทึมมาตรฐานอื่น ใช้สำหรับเข้ารหัสการตั้งค่าในเครื่อง ตรวจสอบลายนิ้วมือโฮสต์ SSH และคำนวณเช็กซัม ทั้งหมดเป็นการคำนวณในเครื่อง ไม่ใช้เครือข่าย

ไม่มี SDK โฆษณา SDK วิเคราะห์ SDK เก็บข้อมูลแอปขัดข้อง หรือ SDK ล็อกอินโซเชียลในแอป

8. ความเป็นส่วนตัวของเด็ก

แอปนี้ไม่เก็บข้อมูลจากเด็กหรือจากใครก็ตาม การจัดระดับอายุบน App Store คือ 4+

9. การเปลี่ยนแปลงนโยบาย

หากนโยบายนี้เปลี่ยนแปลง จะมีการปรับวันที่ “อัปเดตล่าสุด” ที่ด้านบนของหน้า และการเปลี่ยนแปลงจะออกพร้อมเวอร์ชันใหม่ เนื่องจากแอปไม่เก็บข้อมูล การเปลี่ยนแปลงที่มีนัยสำคัญจึงมีโอกาสน้อย

English summary (for App Review reference)

FileExplorer8 does not collect, transmit, or share any user data.

  • No analytics, no ads, no crash reporting, no accounts.
  • All settings and credentials stay on the user's Mac. Passwords live in the macOS Keychain; server endpoints in a local file encrypted with AES-256-GCM (the key ships inside the app, so this obfuscates endpoints rather than protecting against local attackers).
  • The only network capability is an SSH/SFTP client that connects only to servers the user adds. We operate no servers and receive nothing.
  • The app runs in the App Sandbox and requests only user-selected file access, standard folders (Downloads / Documents / Music / Pictures / Movies), and outbound network access.
  • Two open-source dependencies: SwiftSFTP (embedded libssh2 + OpenSSL) and Apple's swift-crypto; both run fully locally with no telemetry.
