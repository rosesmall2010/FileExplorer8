FileExplorer8 tidak mengumpulkan, mengirim, atau membagikan data pengguna apa pun. Tanpa akun, tanpa analitik, tanpa SDK iklan, tanpa laporan kerusakan. Semua yang Anda lihat di aplikasi tetap di Mac Anda.

1. Yang tidak kami kumpulkan

Tidak satu pun dari berikut dikumpulkan — tidak satu butir:

  • Berkas dan folder Anda (isi, nama, ukuran, tanggal modifikasi)
  • Riwayat penjelajahan dan pencarian, isi papan klip
  • Alamat server, akun, sandi, dan kunci privat yang Anda hubungi
  • Pengenal perangkat (nomor seri, UUID perangkat keras, pengenal iklan)
  • Statistik penggunaan, log kerusakan, data kinerja
  • Lokasi, kontak, kalender, pustaka foto, mikrofon, kamera, isi layar Anda

Tidak ada satu pun permintaan jaringan di aplikasi untuk mengirim data. Selain koneksi SSH/SFTP yang Anda mulai sendiri, aplikasi tidak mengirim satu bita pun ke server mana pun.

2. Di mana data disimpan

Semua pengaturan dan kredensial hanya ada di Mac ini, di tiga tempat:

Sandi tidak pernah masuk ke berkas. servers.json hanya berisi titik koneksi, tanpa rahasia. Sandi dan frasa sandi ada di Keychain dan terhapus bersama koneksinya.

Agar jelas: kunci enkripsi servers.json dikirim bersama aplikasi (dikompilasi ke dalam biner — tidak ditulis terpisah ke disk, juga tidak di Keychain). Enkripsi ini hanya mencegah titik koneksi dibaca sembarangan; ia bukan perlindungan terhadap penyerang lokal, sebab siapa yang bisa membaca disk Anda juga bisa membaca biner aplikasinya. Yang benar-benar perlu dirahasiakan — sandi dan frasa sandi — hanya ada di Keychain.

Berkas kunci privat Anda tetap di tempat Anda meletakkannya. Aplikasi hanya menyimpan penanda baca; tidak pernah menyalin atau memindahkannya.

3. Akses jaringan

Aplikasi punya tepat satu kemampuan jaringan: klien SSH / SFTP.

  • Koneksi hanya dibuat setelah Anda menambahkan server dan menekan hubungkan, menuju alamat yang Anda masukkan
  • Digunakan untuk menjelajah dan memindahkan berkas lewat SSH (subsistem SFTP)
  • Kunci host diperiksa dengan cara known_hosts; sidik jari yang berubah akan meminta konfirmasi Anda
  • Data yang dipindahkan dienkripsi oleh SSH itu sendiri (OpenSSL sebagaimana tertanam di libssh2)

Kami tidak mengoperasikan server apa pun dan tidak ada relai atau sinkronisasi awan. Berkas Anda tidak pernah melewati kami.

Aplikasi tidak memeriksa pembaruan, tidak memuat iklan jarak jauh, dan tidak memanggil API pihak ketiga.

Aplikasi tidak meminta: kontak, kalender, pengingat, pustaka foto, kamera, mikrofon, perekaman layar, akses seluruh disk, atau aksesibilitas. Jika Anda melihat FileExplorer8 di salah satu butir itu pada Pengaturan Sistem › Privasi & Keamanan, itu bukan dari aplikasi ini.

Anda dapat mencabut folder yang telah diberikan kapan saja di Pengaturan Sistem › Privasi & Keamanan › Berkas dan Folder.

5. Checksum

Aplikasi dapat menghitung checksum (SHA-256 / SHA-512 / SHA-1 / MD5 / BLAKE3 / CRC32 / CRC64) untuk memeriksa keutuhan berkas.

Fitur ini hanya membaca berkas yang Anda pilih secara eksplisit, menghitung ringkasannya di memori, lalu menampilkannya. Tidak disimpan, tidak dikirim. Ringkasan tidak pernah keluar dari Mac Anda dan tidak masuk ke log mana pun.

7. Komponen pihak ketiga

Aplikasi hanya memuat dua dependensi sumber terbuka:

KomponenKegunaanCatatan
SwiftSFTPImplementasi protokol SSH / SFTPMenyertakan sumber libssh2 dan OpenSSL; berjalan sepenuhnya lokal, tanpa kode analitik atau pengiriman
swift-cryptoPrimitif kriptografi (dari Apple)AES-256-GCM, SHA-2, HMAC dan algoritme standar lain; dipakai untuk enkripsi pengaturan lokal, verifikasi sidik jari host SSH, dan checksum. Sepenuhnya lokal, tidak pernah ke jaringan

Tidak ada SDK iklan, SDK analitik, SDK pengumpul kerusakan, atau SDK login sosial di aplikasi.

8. Privasi anak

Aplikasi ini tidak mengumpulkan informasi dari anak maupun dari siapa pun. Peringkat usia di App Store adalah 4+.

9. Perubahan kebijakan

Bila kebijakan ini berubah, tanggal “Terakhir diperbarui” di atas halaman diperbarui dan perubahannya menyertai versi baru. Karena aplikasi tidak mengumpulkan data, perubahan mendasar kecil kemungkinannya.

English summary (for App Review reference)

FileExplorer8 does not collect, transmit, or share any user data.

  • No analytics, no ads, no crash reporting, no accounts.
  • All settings and credentials stay on the user's Mac. Passwords live in the macOS Keychain; server endpoints in a local file encrypted with AES-256-GCM (the key ships inside the app, so this obfuscates endpoints rather than protecting against local attackers).
  • The only network capability is an SSH/SFTP client that connects only to servers the user adds. We operate no servers and receive nothing.
  • The app runs in the App Sandbox and requests only user-selected file access, standard folders (Downloads / Documents / Music / Pictures / Movies), and outbound network access.
  • Two open-source dependencies: SwiftSFTP (embedded libssh2 + OpenSSL) and Apple's swift-crypto; both run fully locally with no telemetry.
