文件8 不收集、不上传、不分享任何用户数据。没有账号体系，没有统计分析，没有广告 SDK，没有崩溃上报。你在应用里看到的一切文件都留在你自己的机器上。

一、我们不收集什么

以下数据一项都不收集：

  • 你的文件与文件夹（内容、名称、大小、修改时间）
  • 你的浏览历史、搜索记录、剪贴板内容
  • 你连接的服务器地址、账号、密码、私钥
  • 设备标识（序列号、硬件 UUID、广告标识符）
  • 使用统计、崩溃日志、性能数据
  • 你的位置、通讯录、日历、相册、麦克风、摄像头、屏幕内容

应用内没有任何用于数据上报的网络请求。除你主动发起的 SSH/SFTP 连接外，应用不会向任何服务器发送任何字节。

二、数据存在哪里

所有配置与凭据都只存在于这台 Mac 上，分三处：

位置存什么保护方式
应用沙盒容器
~/Library/Containers/com.donghuazhu.FileExplorer8/		偏好设置、会话现场（窗口位置、各栏路径等）、快速访问书签App Sandbox 容器内，仅本应用可访问
同上，servers.jsonSSH 服务器端点（主机、端口、用户名、显示名）AES-256-GCM 加密（swift-crypto）
系统钥匙串（Keychain）SSH 密码、私钥口令由 macOS 钥匙串保护

密码与口令不进文件。 servers.json 里只有端点信息，没有秘密；密码与私钥口令存在系统钥匙串，删除某条连接时一并删除。

需要说明的是，servers.json 的加密密钥随应用一同分发（编译进程序内，不单独落盘、也不在钥匙串里）。这道加密只是防止端点信息被随意翻看，不构成针对本机攻击者的保护——能读你磁盘的人也能读应用本体。真正需要保密的内容（密码、口令）始终只在钥匙串里。

私钥文件本身永远留在你自己放的位置，应用只保存一个文件书签用于读取，不复制、不移动到别处。

三、网络访问

应用只有一个网络能力：SSH / SFTP 客户端。

  • 只在你主动添加服务器并点击连接时才发起连接，目标是你自己填的地址
  • 连接用途是浏览与传输文件，协议为 SSH（SFTP 子系统）
  • 主机密钥按 known_hosts 方式校验，指纹变化会提示你确认
  • 传输内容经过 SSH 协议自身的加密（libssh2 内置 OpenSSL 实现）

我们不运营任何服务器，也没有任何中转或云同步服务。你的文件不经过我们。

应用不检查更新、不加载远程广告、不请求任何第三方接口。

四、系统权限

应用开启 App Sandbox，只在你授予的范围内读写文件：

权限用途何时出现
用户选择的文件浏览与操作你指定的目录首次进入沙盒外的目录时由系统弹窗
下载 / 文稿 / 音乐 / 图片 / 影片文件夹免弹窗直接访问这几个标准位置安装后即可用
网络访问（出站）连接你自己添加的 SSH 服务器仅在你点击连接时

上表与应用包内实际的沙盒权限一一对应（app-sandbox、files.user-selected、files.downloads、assets.music / assets.pictures / assets.movies、network.client），没有多申请任何一项。

应用不申请：通讯录、日历、提醒事项、照片库、摄像头、麦克风、屏幕录制、完全磁盘访问、辅助功能。若你在「系统设置 › 隐私与安全性」里看到这些项目下有文件8，那不是本应用申请的。

你也可以随时在「系统设置 › 隐私与安全性 › 文件和文件夹」里撤销已授予的目录。

五、文件校验和功能

应用提供「计算校验和」（SHA-256 / SHA-512 / SHA-1 / MD5 / BLAKE3 / CRC32 / CRC64），用于核对文件完整性。

这项功能只读取你明确选中的文件，在内存中计算摘要并显示给你，不保存、不上传。摘要值不会离开你的机器，也不会进入任何日志。

六、删除你的数据

想删什么怎么做
某条 SSH 连接的密码应用内删除该连接，钥匙串里的密码与口令随之删除
全部偏好与会话应用内「重置」功能，或删除 ~/Library/Containers/com.donghuazhu.FileExplorer8/
全部数据卸载应用，再删除上面那个目录

我们这边没有你的任何数据，因此不存在「向我们申请删除」的流程——也无需注销账号，本应用没有账号。

七、第三方组件

应用只包含两个开源依赖：

组件用途说明
SwiftSFTPSSH / SFTP 协议实现内嵌 libssh2 与 OpenSSL 源码，纯本地运行，不含任何统计或联网上报代码
swift-crypto加密原语（Apple 官方）AES-256-GCM、SHA-2、HMAC 等标准算法；用于本地配置加密、SSH 主机指纹校验与文件校验和计算，纯本地运算，不联网

应用内没有广告 SDK、统计分析 SDK、崩溃收集 SDK、社交登录 SDK。

八、儿童隐私

本应用不面向儿童定向收集任何信息，也不收集任何人的信息。App Store 年龄分级为 4+。

九、政策变更

本政策如有修改，会更新本页顶部的「最后更新」日期，并随新版本发布。由于本应用不收集数据，实质性变更的可能性很低。

English summary (for App Review reference)

FileExplorer8 does not collect, transmit, or share any user data.

  • No analytics, no ads, no crash reporting, no accounts.
  • All settings and credentials stay on the user's Mac. Passwords live in the macOS Keychain; server endpoints in a local file encrypted with AES-256-GCM (the key ships inside the app, so this obfuscates endpoints rather than protecting against local attackers).
  • The only network capability is an SSH/SFTP client that connects only to servers the user adds. We operate no servers and receive nothing.
  • The app runs in the App Sandbox and requests only user-selected file access, standard folders (Downloads / Documents / Music / Pictures / Movies), and outbound network access.
  • Two open-source dependencies: SwiftSFTP (embedded libssh2 + OpenSSL) and Apple's swift-crypto; both run fully locally with no telemetry.
