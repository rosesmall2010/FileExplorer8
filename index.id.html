Dukungan

Terjebak, punya ide, atau menemukan bug?

Buka issue di GitHub Issues dan sertakan versi macOS, versi FileExplorer8, serta langkah mereproduksinya. Tangkapan layar sangat membantu.

Nomor versi ada di “FileExplorer8 › Tentang FileExplorer8”.

Pertanyaan umum

Mengapa muncul permintaan izin saat membuka beberapa folder?
Aplikasi berjalan di App Sandbox. Desktop, Unduhan, Dokumen, dan disk eksternal berada di luar sandbox, jadi macOS meminta izin saat pertama kali masuk ke folder tersebut. Itu rancangan keamanan sistem, bukan cacat. Pilih “Izinkan akses ke folder ini” dan folder akan diingat — satu jalur hanya ditanyai sekali per sesi jalan.

Apakah aplikasi membaca kontak, kamera, atau layar saya?
Tidak. FileExplorer8 hanya meminta akses berkas yang Anda pilih, folder standar (Unduhan / Dokumen / Musik / Gambar / Film), dan akses jaringan keluar. Tidak ada akses kontak, kamera, mikrofon, perekaman layar, atau seluruh disk.

Di mana sandi SSH disimpan?
Di Keychain macOS. Titik koneksi server disimpan di kontainer sandbox lokal, dienkripsi dengan AES-256-GCM. Anda juga bisa tidak menyimpan sandi dan menerima kotak masuk sekali pakai pada setiap koneksi. Lihat kebijakan privasi.

Apakah mendukung Apple Silicon dan Intel?
Keduanya. Pemasangnya adalah biner universal. Diperlukan macOS 15.0 atau lebih baru.

Bagaimana membersihkan sisa data setelah menghapus aplikasi?
Hapus aplikasi, lalu hapus ~/Library/Containers/com.donghuazhu.FileExplorer8/ untuk membersihkan preferensi, status sesi, dan titik koneksi server (aplikasi dalam sandbox menyimpan data di kontainer ini, bukan di lokasi bersama sistem). Sandi SSH ada di Keychain dan terhapus bersama koneksinya.

Fitur

FileExplorer8 menggabungkan tiga model interaksi ke dalam satu jendela. Tekan ⇧⌘D untuk bergilir; tiap mode menyimpan statusnya sendiri — jalur, tab, pengurutan, lebar kolom, pilihan.

  • Pengelola berkas: Menjelajah dan merapikan. Pohon samping, bilah jalur, tab lengkap, enam tata letak tampilan.
  • Dua panel: Model sumber / tujuan dengan sembilan tombol bilah tindakan untuk pemindahan massal.
  • Empat panel: Kisi 2×2 untuk melihat empat folder sekaligus dan membagi ke beberapa tujuan.
  • Uji coba sebelum menulis: Menyalin, memindahkan, dan menimpa selalu dimulai dengan hasil uji coba. Langkah ini tidak menulis satu bita pun.
  • Urungkan tiga tingkat: Pemindahan dalam volume sama, penggantian nama, hapus ke Tempat Sampah, serta pemadatan dan ekstraksi ZIP dijamin dapat diurungkan.
  • Pratinjau: Spasi untuk Pratinjau Cepat, kode sumber dengan penyorotan sintaks, PDF lewat PDFKit, berkas SSH jarak jauh hingga 10 MB.
  • Folder SSH jarak jauh: Terhubung dengan sandi atau kunci privat; folder jarak jauh diperlakukan seperti folder lokal.
  • 14 bahasa: Tionghoa sederhana dan tradisional, Inggris, Jepang, Korea, Jerman, Prancis, Spanyol, Portugis Brasil, Rusia, Vietnam, Indonesia, Melayu, Thai.
