## これは何か

FileExplorer8 は macOS 上でネイティブに動作する**ファイルマネージャ**です。「ファイラ」「2 ペイン」「4 ペイン」という 3 つの操作形態を 1 つのウィンドウに収め、`⇧⌘D` で順に切り替えます。各形態はパス、タブ、並び順、列幅、選択項目をそれぞれ保持し、行き来しても失われません。

Finder の代替ではなく、Finder の別スキンでもありません。Finder に足りない部分、すなわち**両手をキーボードに置いたままのまとまった移動**を補います。

参照しているのは古典的な 2 ペイン方式のファイルマネージャです。既定のアプリにはならず、Finder 拡張も作らず、Finder の環境設定も読み書きしません。共有するのはファイルシステムそのものだけなので、Finder と長く併存しても衝突しません。

## 機能

### 書き込み前に必ずドライラン

コピー、移動、上書きの前にドライランを行います。書き込み先に書けるか、空き容量は足りるか、どの名前が衝突するかを先に提示します。**この段階では 1 バイトも書き込みません。**

衝突時の方式は 4 つから選べます。置き換え（先にバックアップし、取り消し可能）、両方残す、スキップ、1 件ずつ確認。衝突が 5 件以下なら個別に判断できます。

進行状況には実効速度、転送済み／総量／残量を表示し、終了時には成功・スキップ・失敗の件数をまとめた結果を出します。失敗した項目はファイル名と理由を 1 件ずつ示します。

### 3 段階の取り消し

同一ボリューム内の移動、名前変更、ゴミ箱への削除、ZIP の圧縮と解凍は**100% 取り消せます**。コピーとボリュームをまたぐ移動はベストエフォートです。取り消せない操作は実行前に再確認します。

### 6 種類の表示と本格プレビュー

特大／大／中／小アイコン、リスト、詳細表示。アイコンは実際のピクセル数（256 / 128 / 64 / 32）で出し分けるため、Retina でも輪郭がぼやけません。

`Space` でプレビューし、`←` / `→` や `PgUp` / `PgDn` で続けて移動できます：

- テキストとソースコードは読み取り専用の等幅表示。50 以上の言語の色分けと行番号付き
- PDF は PDFKit で表示
- 画像は縦横比を保ったままパネル全体に収まるよう拡大縮小
- リッチな形式はシステムの Quick Look に委ねる
- 表示できないものは概要情報を提示

### 圧縮と解凍

**ZIP に圧縮**：ZIP64、圧縮レベルの調整、すでに圧縮済みの形式は自動でスキップ、シンボリックリンクを辿るか選択可能。結果は取り消せます。

**ダブルクリックで解凍**。挙動は Finder と同じで、単一の最上位フォルダは入れ子にせず、衝突時はアーカイブ全体を改名し、`__MACOSX` だけを削除して Unix のパーミッションを復元します。

### SSH リモートフォルダ

SSH / SFTP を内蔵。パスワードまたは任意の場所にある秘密鍵で接続し、リモートのフォルダもローカルと同じように閲覧、コピー、削除、名前変更、取り消しができます。書き込みは同じ経路を通ります。

タブにはネットワークドライブのアイコンと赤緑の状態で接続状況を示し、切断後はワンクリックで再接続できます。**パスワードは保存しない**こともでき、その場合は接続のたびに一度だけログインを尋ねます。リモートのファイルも 10 MB までなら素早くプレビューできます。

### 細部

- Finder の 7 色タグに対応し、重ねて付与可能。すべて外したときは独自のテキストタグを残す
- コマンドパレット `⌘K`。一致度 → 最近の使用 → アルファベット順で並ぶ
- パスの 3 種：パスをコピー、親フォルダのパスをコピー、ファイル名をコピー。加えて「ターミナルで開く」
- チェックサム：SHA-256 / SHA-512 / SHA-1 / MD5 / BLAKE3 / CRC32 / CRC64
- ボリュームの自動検出：USB メモリ、外付けドライブ、マウント済みのディスクイメージが自動で現れ、ワンクリックで取り出せる
- セッション復元：ウィンドウ位置、タブ、列幅、並び順、ペインの比率を記憶。クラッシュ後も待機中の書き込みを再開
- Finder との双方向コピー＆ペースト、3 方向のドラッグ＆ドロップに対応
- 言語の切り替えはメニューバーの最上位「言語」メニューにあり、1 手順ですぐ、切り替えは即座に反映

### 14 言語

簡体中国語、繁体中国語、英語、日本語、韓国語、ドイツ語、フランス語、スペイン語、ブラジルポルトガル語、ロシア語、ベトナム語、インドネシア語、マレー語、タイ語。

タイ語は独自の照合順序を実装しています。前置母音、声調記号、文字の順序はいずれもコードポイント順ではないため、コードポイントで並べると崩れます。

## プライバシー

**データの収集はありません。** アカウントも統計も広告 SDK もクラッシュ報告もありません。

ご自身で開始した SSH 接続を除き、アプリはどのサーバーにも 1 バイトも送信しません。ファイル、閲覧履歴、サーバーの認証情報はすべてお使いの Mac に留まります。パスワードとパスフレーズはシステムキーチェーンに、秘密鍵ファイルはあなたが置いた場所にあります。

アプリは App Sandbox を有効にし、許可したフォルダの範囲内でのみ読み書きします。連絡先、カメラ、マイク、画面収録、フルディスクアクセスは要求しません。

[プライバシーポリシーを読む](https://rosesmall2010.github.io/FileExplorer8/privacy.ja.html)

### よくある質問

**フォルダを開くと許可を求められるのはなぜですか？**
App Sandbox を有効にしているためです。デスクトップ、ダウンロード、書類、外付けディスクなどはサンドボックスの外にあり、そのフォルダに初めて入るときに macOS が必ず確認します。これはシステムの安全設計であり、不具合ではありません。「このフォルダへのアクセスを許可」を選べば記憶され、同じパスにつき 1 回の起動で 1 度だけ尋ねられます。

**連絡先やカメラ、画面を読み取りますか？**
いいえ。FileExplorer8 が要求するのは、ユーザが選択したファイルへのアクセス、標準フォルダ（ダウンロード／書類／ミュージック／ピクチャ／ムービー）、および外向きのネットワークアクセスだけです。連絡先、カメラ、マイク、画面収録、フルディスクアクセスの権限はありません。

**SSH のパスワードはどこに保存されますか？**
macOS のキーチェーンです。サーバーのエンドポイント情報はローカルのサンドボックスコンテナ内に AES-256-GCM で暗号化して保存されます。パスワードを保存せず、接続のたびに一度だけログインを尋ねる設定にもできます。詳しくは<a href="https://rosesmall2010.github.io/FileExplorer8/privacy.ja.html">プライバシーポリシー</a>をご覧ください。

**Apple Silicon と Intel の両方に対応していますか？**
はい。インストーラはユニバーサルバイナリです。macOS 15.0 以降が必要です。

**アンインストール後の残りデータはどう消しますか？**
アプリを削除したあと、<code>~/Library/Containers/com.donghuazhu.FileExplorer8/</code> を削除すると、環境設定・セッション状態・サーバーのエンドポイント情報が消えます（サンドボックスアプリのデータはこのコンテナ内にあり、システムの共有領域には置かれません）。SSH のパスワードはキーチェーンにあり、該当する接続を削除すると一緒に削除されます。
