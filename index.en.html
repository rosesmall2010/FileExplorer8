Open an issue on GitHub Issues and include your macOS version, your FileExplorer8 version, and the steps that reproduce the problem. A screenshot helps a lot.

Frequently asked

Why does it ask for permission when I open some folders?
The app runs in the App Sandbox. Desktop, Downloads, Documents and external disks live outside the sandbox, so macOS prompts you the first time you enter such a folder. That is the system's security design, not a defect. Choose “Grant access to this folder” and the folder is remembered — you are only asked once per path per run.

Does it read my contacts, camera, or screen?
No. FileExplorer8 only requests user-selected file access, the standard folders (Downloads / Documents / Music / Pictures / Movies), and outbound network access. It has no contacts, camera, microphone, screen-recording or full-disk access.

Where are SSH passwords stored?
In the macOS Keychain. Server endpoints live in the local sandbox container, encrypted with AES-256-GCM. You can also skip saving the password and get a one-time login prompt on every connection. See the privacy policy.

Does it support Apple Silicon and Intel?
Both. The installer is a universal binary. macOS 15.0 or later is required.

How do I clean up leftovers after uninstalling?
Delete the app, then delete ~/Library/Containers/com.donghuazhu.FileExplorer8/ to clear preferences, session state and server endpoints (sandboxed apps keep their data in that container, not in shared system locations). SSH passwords live in the Keychain and are removed along with their connections.

Features

FileExplorer8 packs three interaction models into one window. Press ⇧⌘D to cycle through them; each mode keeps its own state — path, tabs, sorting, column widths, selection.

  • File manager: Explore and tidy up. Sidebar tree, path bar, full tabs, six view layouts.
  • Dual-pane: Source / destination model with nine action-bar buttons for bulk transfer.
  • Quad-pane: A 2×2 grid to watch four folders at once and fan out to several targets.
  • Dry-run first: Copy, move and overwrite each start with a dry-run verdict. That step writes zero bytes.
  • Three-tier undo: Same-volume moves, renames, trash deletes and ZIP pack/unpack are guaranteed undoable.
  • Preview: Space for Quick Look, syntax-highlighted source code, PDFs via PDFKit, and remote SSH files up to 10 MB.
  • Remote SSH folders: Connect with a password or a private key; remote folders behave like local ones.
  • 14 languages: Simplified Chinese, Traditional Chinese, English, Japanese, Korean, German, French, Spanish, Brazilian Portuguese, Russian, Vietnamese, Indonesian, Malay, Thai.
