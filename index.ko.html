자주 묻는 질문

폴더를 열 때 권한을 묻는 이유는 무엇인가요?
App Sandbox를 켜 두었기 때문입니다. 데스크탑, 다운로드, 문서, 외장 디스크 등은 샌드박스 밖에 있어 해당 폴더에 처음 들어갈 때 macOS가 반드시 확인을 요청합니다. 이는 시스템의 안전 설계이며 결함이 아닙니다. “이 폴더에 대한 접근 허용”을 선택하면 기억되며, 같은 경로는 한 번 실행에 한 번만 묻습니다.

연락처나 카메라, 화면을 읽나요?
아니요. FileExplorer8이 요청하는 것은 사용자가 선택한 파일 접근, 표준 폴더(다운로드 / 문서 / 음악 / 사진 / 동영상), 그리고 외부 네트워크 접근뿐입니다. 연락처, 카메라, 마이크, 화면 기록, 전체 디스크 접근 권한은 없습니다.

SSH 비밀번호는 어디에 저장되나요?
macOS 키체인에 저장됩니다. 서버 엔드포인트 정보는 로컬 샌드박스 컨테이너 안에 AES-256-GCM으로 암호화되어 있습니다. 비밀번호를 저장하지 않고 연결할 때마다 한 번씩 로그인하도록 할 수도 있습니다. 자세한 내용은 개인정보 처리방침을 보세요.

Apple Silicon과 Intel을 모두 지원하나요?
둘 다 지원합니다. 설치 파일은 유니버설 바이너리입니다. macOS 15.0 이상이 필요합니다.

앱을 삭제한 뒤 남은 데이터는 어떻게 정리하나요?
앱을 삭제한 다음 ~/Library/Containers/com.donghuazhu.FileExplorer8/을 삭제하면 환경설정, 세션 상태, 서버 엔드포인트 정보가 지워집니다(샌드박스 앱의 데이터는 이 컨테이너 안에 있으며 시스템 공용 위치에 있지 않습니다). SSH 비밀번호는 키체인에 있고, 해당 연결을 삭제하면 함께 삭제됩니다.

기능

FileExplorer8은 세 가지 조작 방식을 한 창에 담았고 ⇧⌘D로 차례로 전환합니다. 각 형태는 경로, 탭, 정렬, 열 너비, 선택 항목을 각자 기억합니다.

  • 파일 관리자: 탐색과 정리. 사이드바 트리, 경로 막대, 전체 탭, 여섯 가지 보기 레이아웃.
  • 2분할 관리자: 원본 / 대상 방식에 아홉 개 실행 막대 버튼으로 대량 전송.
  • 4분할 관리자: 2×2 배치로 네 폴더를 동시에 보며 여러 대상으로 나눠 전송.
  • 쓰기 전 사전 점검: 복사, 이동, 덮어쓰기 전에 미리 결과를 보여 줍니다. 이 단계에서는 단 1바이트도 쓰지 않습니다.
  • 3단계 실행 취소: 같은 볼륨 내 이동, 이름 변경, 휴지통 삭제, ZIP 압축·해제는 실행 취소가 보장됩니다.
  • 미리보기: Space로 빠른 보기. 소스 코드는 구문 강조, PDF는 PDFKit, SSH 원격 파일도 10 MB까지 볼 수 있습니다.
  • SSH 원격 폴더: 비밀번호나 개인 키로 연결하고 원격도 로컬처럼 다룹니다.
  • 14개 언어: 중국어 간체, 중국어 번체, 영어, 일본어, 한국어, 독일어, 프랑스어, 스페인어, 브라질 포르투갈어, 러시아어, 베트남어, 인도네시아어, 말레이어, 태국어.
