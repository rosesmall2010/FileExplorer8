Sokongan

Terhenti, ada idea, atau jumpa pepijat?

Buka isu di GitHub Issues dan sertakan versi macOS, versi FileExplorer8 serta langkah untuk menghasilkan semula masalah. Tangkapan skrin sangat membantu.

Nombor versi ada di “FileExplorer8 › Perihal FileExplorer8”.

Soalan lazim

Mengapa ia meminta kebenaran apabila membuka sesetengah folder?
Aplikasi berjalan dalam App Sandbox. Desktop, Muat Turun, Dokumen dan cakera luaran berada di luar sandbox, jadi macOS bertanya kali pertama anda masuk ke folder tersebut. Itu reka bentuk keselamatan sistem, bukan kecacatan. Pilih “Benarkan akses ke folder ini” dan folder itu akan diingati — satu laluan hanya ditanya sekali bagi setiap kali jalan.

Adakah ia membaca kenalan, kamera atau skrin saya?
Tidak. FileExplorer8 hanya meminta akses fail yang anda pilih, folder piawai (Muat Turun / Dokumen / Muzik / Gambar / Filem) dan akses rangkaian keluar. Tiada akses kepada kenalan, kamera, mikrofon, rakaman skrin atau keseluruhan cakera.

Di manakah kata laluan SSH disimpan?
Dalam Keychain macOS. Titik sambungan pelayan disimpan dalam bekas sandbox tempatan, disulitkan dengan AES-256-GCM. Anda juga boleh tidak menyimpan kata laluan dan menerima kotak log masuk sekali guna bagi setiap sambungan. Lihat dasar privasi.

Adakah ia menyokong Apple Silicon dan Intel?
Kedua-duanya. Pemasang ialah binari universal. macOS 15.0 atau lebih baru diperlukan.

Bagaimana hendak membersihkan sisa data selepas menyahpasang?
Padam aplikasi, kemudian padam ~/Library/Containers/com.donghuazhu.FileExplorer8/ untuk mengosongkan keutamaan, keadaan sesi dan titik sambungan pelayan (aplikasi dalam sandbox menyimpan data dalam bekas ini, bukan di lokasi kongsi sistem). Kata laluan SSH ada dalam Keychain dan terpadam bersama sambungannya.

Ciri

FileExplorer8 menggabungkan tiga model interaksi ke dalam satu tetingkap. Tekan ⇧⌘D untuk berputar; setiap mod menyimpan keadaannya sendiri — laluan, tab, susunan, lebar lajur, pilihan.

  • Pengurus fail: Menjelajah dan menyusun. Pokok sisi, bar laluan, tab penuh, enam susun atur paparan.
  • Dua anak tetingkap: Model sumber / destinasi dengan sembilan butang bar tindakan untuk pemindahan pukal.
  • Empat anak tetingkap: Grid 2×2 untuk melihat empat folder serentak dan mengagihkan ke beberapa destinasi.
  • Cuba dahulu sebelum menulis: Salin, pindah dan timpa semuanya bermula dengan keputusan percubaan. Langkah ini tidak menulis satu bait pun.
  • Buat asal tiga peringkat: Pemindahan dalam volum sama, penamaan semula, padam ke Tong Sampah serta mampat dan ekstrak ZIP dijamin boleh dibuat asal.
  • Pratonton: Ruang untuk Paparan Pantas, kod sumber dengan penyerlahan sintaks, PDF melalui PDFKit, fail SSH jauh sehingga 10 MB.
  • Folder SSH jauh: Sambung dengan kata laluan atau kunci peribadi; folder jauh berkelakuan seperti folder tempatan.
  • 14 bahasa: Cina ringkas dan tradisional, Inggeris, Jepun, Korea, Jerman, Perancis, Sepanyol, Portugis Brazil, Rusia, Vietnam, Indonesia, Melayu, Thai.
