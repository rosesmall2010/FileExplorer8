## นี่คืออะไร

FileExplorer8 คือ**ตัวจัดการไฟล์**ที่ทำงานบน macOS โดยตรง รวมสามรูปแบบการใช้งาน ได้แก่ ตัวจัดการไฟล์ สองบานหน้าต่าง และสี่บานหน้าต่าง ไว้ในหน้าต่างเดียว สลับวนด้วย `⇧⌘D` แต่ละโหมดจำสถานะของตนเอง ทั้งเส้นทาง แท็บ การเรียงลำดับ ความกว้างคอลัมน์ และรายการที่เลือก สลับไปกลับก็ไม่สูญหาย

ไม่ใช่ตัวแทนของ Finder และไม่ใช่เปลือกหน้าตาอีกชั้นของ Finder แต่เติมสิ่งที่ Finder ขาด นั่นคือ**การย้ายข้อมูลจำนวนมากโดยที่มือทั้งสองอยู่บนแป้นพิมพ์**

ต้นแบบอ้างอิงคือตัวจัดการไฟล์สองบานหน้าต่างแบบคลาสสิก ที่ไม่ตั้งโปรแกรมเปิดเริ่มต้น ไม่สร้างส่วนขยาย Finder และไม่อ่านหรือเขียนการตั้งค่าของ Finder สิ่งเดียวที่ใช้ร่วมกันคือระบบไฟล์เอง จึงอยู่ร่วมกับ Finder ได้ยาวนานโดยไม่ขัดกัน

## คุณสมบัติ

### ทดลองก่อนเขียนทุกครั้ง

ก่อนคัดลอก ย้าย หรือเขียนทับ แอปจะทดลองก่อน: ปลายทางเขียนได้หรือไม่ พื้นที่พอหรือไม่ ชื่อใดชนกัน ทั้งหมดจะแสดงให้ดูก่อน **ขั้นตอนนี้ไม่เขียนแม้แต่ไบต์เดียว**

สี่กลยุทธ์เมื่อเกิดการชน: แทนที่ (สำรองก่อน เลิกทำได้) เก็บไว้ทั้งคู่ ข้าม ถามทีละรายการ หากชนกันไม่เกินห้ารายการ คุณตัดสินใจทีละรายการได้

ความคืบหน้าแสดงความเร็วจริง จำนวนที่ส่งแล้ว / ทั้งหมด / ที่เหลือ และจบด้วยสรุปครบถ้วน: สำเร็จกี่รายการ ข้ามกี่รายการ ล้มเหลวกี่รายการ พร้อมระบุชื่อไฟล์และสาเหตุของทุกความล้มเหลว

### เลิกทำสามระดับ

การย้ายภายในโวลุ่มเดียวกัน การเปลี่ยนชื่อ การลบลงถังขยะ และการบีบอัดหรือแตกไฟล์ ZIP **รับประกันว่าเลิกทำได้ 100%** การคัดลอกและการย้ายข้ามโวลุ่มทำให้ดีที่สุดเท่าที่ทำได้ การดำเนินการที่เลิกทำไม่ได้จะขอให้ยืนยันก่อน

### หกมุมมองและการดูตัวอย่างจริง

ไอคอนใหญ่พิเศษ / ใหญ่ / กลาง / เล็ก แบบรายการ และแบบรายละเอียด ไอคอนเลือกตามขนาดพิกเซลจริง (256 / 128 / 64 / 32) จึงไม่เบลอบนจอ Retina

กด `Space` เพื่อดูตัวอย่าง แล้วใช้ `←` / `→` หรือ `PgUp` / `PgDn` เลื่อนต่อ:

- ข้อความและซอร์สโค้ดแสดงแบบอ่านอย่างเดียวด้วยฟอนต์ความกว้างคงที่ พร้อมไฮไลต์ไวยากรณ์กว่า 50 ภาษาและเลขบรรทัด
- PDF แสดงผ่าน PDFKit
- รูปภาพย่อขยายให้พอดีแผงโดยรักษาสัดส่วน
- รูปแบบที่ซับซ้อนส่งให้ Quick Look ของระบบ
- สิ่งที่แสดงไม่ได้จะได้รับบัตรข้อมูลแทน

### บีบอัดและแตกไฟล์

**สร้าง ZIP**: ZIP64 ปรับระดับการบีบอัดได้ ข้ามรูปแบบที่บีบอัดอยู่แล้วโดยอัตโนมัติ เลือกได้ว่าจะตาม symbolic link หรือไม่ และผลลัพธ์เลิกทำได้

**ดับเบิลคลิกเพื่อแตกไฟล์** พฤติกรรมเดียวกับ Finder: โฟลเดอร์บนสุดเพียงโฟลเดอร์เดียวจะไม่ซ้อนอีกชั้น เมื่อชนกันจะเปลี่ยนชื่อทั้งแพ็กเกจ ล้างเฉพาะ `__MACOSX` และคืนค่าบิตสิทธิ์แบบ Unix

### โฟลเดอร์ SSH ระยะไกล

มี SSH / SFTP ในตัว เชื่อมต่อด้วยรหัสผ่านหรือคีย์ส่วนตัวจากเส้นทางใดก็ได้ แล้วเรียกดู คัดลอก ลบ เปลี่ยนชื่อ และเลิกทำบนฝั่งระยะไกลได้เหมือนในเครื่อง ผ่านท่อการเขียนเดียวกัน

แถบแท็บแสดงสถานะการเชื่อมต่อด้วยไอคอนดิสก์เครือข่ายและสถานะสีแดงหรือเขียว และเชื่อมต่อใหม่ได้ในคลิกเดียวเมื่อหลุด **เลือกไม่บันทึกรหัสผ่านได้** โดยจะมีหน้าต่างเข้าสู่ระบบครั้งเดียวทุกครั้งที่เชื่อมต่อ ไฟล์ระยะไกลไม่เกิน 10 MB ดูตัวอย่างได้ทันที

### รายละเอียด

- แท็กสีเจ็ดสีของ Finder ซ้อนทับกันได้ เมื่อยกเลิกแท็กทั้งหมดจะคงแท็กข้อความที่กำหนดเองไว้
- พาเลตคำสั่ง `⌘K` เรียงตามความตรงกัน → ใช้ล่าสุด → ตัวอักษร
- ชุดเส้นทางสามอย่าง: คัดลอกเส้นทาง คัดลอกเส้นทางโฟลเดอร์แม่ คัดลอกชื่อไฟล์ พร้อม “เปิดใน Terminal”
- คำนวณเช็กซัม: SHA-256 / SHA-512 / SHA-1 / MD5 / BLAKE3 / CRC32 / CRC64
- ตรวจพบโวลุ่มอัตโนมัติ: แฟลชไดรฟ์ ดิสก์ภายนอก อิมเมจดิสก์ที่เมานต์แล้ว จะปรากฏเอง และถอดออกได้ในคลิกเดียว
- กู้คืนเซสชัน: ตำแหน่งหน้าต่าง แท็บ ความกว้างคอลัมน์ การเรียงลำดับ และสัดส่วนสองบานถูกจำไว้ งานเขียนที่รอคิวจะดำเนินต่อหลังแอปหยุดกลางคัน
- คัดลอกวางสองทางกับ Finder และลากวางได้ทั้งสามทิศทาง
- การเปลี่ยนภาษาอยู่ในเมนูภาษาแบบระดับแรก ถึงได้ในขั้นตอนเดียวและมีผลทันที

### 14 ภาษา

จีนตัวย่อ จีนตัวเต็ม อังกฤษ ญี่ปุ่น เกาหลี เยอรมัน ฝรั่งเศส สเปน โปรตุเกสบราซิล รัสเซีย เวียดนาม อินโดนีเซีย มาเลย์ ไทย

ภาษาไทยมีการเรียงลำดับแบบเฉพาะ เพราะสระนำ เครื่องหมายวรรณยุกต์ และลำดับอักษรไม่ตรงกับลำดับรหัสอักขระ การเรียงตามรหัสอักขระจะสลับผิดที่

## ความเป็นส่วนตัว

**ไม่มีการเก็บข้อมูลใด ๆ** ไม่มีบัญชี ไม่มีการวิเคราะห์ ไม่มี SDK โฆษณา ไม่มีการรายงานแอปขัดข้อง

นอกจากเซสชัน SSH ที่คุณเริ่มเอง แอปไม่ส่งแม้แต่ไบต์เดียวไปยังเซิร์ฟเวอร์ใด ไฟล์ ประวัติการใช้งาน และข้อมูลรับรองเซิร์ฟเวอร์ของคุณอยู่บน Mac ของคุณ รหัสผ่านและวลีรหัสผ่านอยู่ในพวงกุญแจของระบบ ไฟล์คีย์ส่วนตัวยังอยู่ที่ที่คุณวางไว้

แอปทำงานใน App Sandbox และอ่านหรือเขียนเฉพาะในโฟลเดอร์ที่คุณอนุญาต ไม่ขอสิทธิ์รายชื่อผู้ติดต่อ กล้อง ไมโครโฟน การบันทึกหน้าจอ หรือดิสก์ทั้งหมด

### คำถามที่พบบ่อย

**ทำไมเปิดบางโฟลเดอร์แล้วมีหน้าต่างขออนุญาต?**
แอปทำงานใน App Sandbox โฟลเดอร์เดสก์ท็อป ดาวน์โหลด เอกสาร และดิสก์ภายนอกอยู่นอก sandbox macOS จึงต้องถามเมื่อคุณเข้าสู่โฟลเดอร์เหล่านั้นครั้งแรก นี่คือการออกแบบความปลอดภัยของระบบ ไม่ใช่ข้อบกพร่อง เมื่อเลือก “อนุญาตให้เข้าถึงโฟลเดอร์นี้” ระบบจะจำโฟลเดอร์ไว้ โดยถามเพียงครั้งเดียวต่อเส้นทางต่อการเปิดโปรแกรมหนึ่งครั้ง

**แอปอ่านรายชื่อผู้ติดต่อ กล้อง หรือหน้าจอของฉันหรือไม่?**
ไม่ FileExplorer8 ขอเพียงการเข้าถึงไฟล์ที่คุณเลือก โฟลเดอร์มาตรฐาน (ดาวน์โหลด / เอกสาร / เพลง / รูปภาพ / ภาพยนตร์) และการเชื่อมต่อเครือข่ายขาออกเท่านั้น ไม่มีสิทธิ์เข้าถึงรายชื่อผู้ติดต่อ กล้อง ไมโครโฟน การบันทึกหน้าจอ หรือดิสก์ทั้งหมด

**รหัสผ่าน SSH เก็บไว้ที่ไหน?**
ในพวงกุญแจ (Keychain) ของ macOS ข้อมูลปลายทางการเชื่อมต่อเซิร์ฟเวอร์เก็บในคอนเทนเนอร์ sandbox ภายในเครื่อง เข้ารหัสด้วย AES-256-GCM คุณยังเลือกไม่บันทึกรหัสผ่านได้ โดยจะมีหน้าต่างเข้าสู่ระบบครั้งเดียวทุกครั้งที่เชื่อมต่อ ดู<a href="privacy.html">นโยบายความเป็นส่วนตัว</a>

**รองรับ Apple Silicon และ Intel หรือไม่?**
รองรับทั้งสอง ตัวติดตั้งเป็นไบนารีสากล ต้องใช้ macOS 15.0 ขึ้นไป

**จะล้างข้อมูลที่เหลือหลังถอนการติดตั้งอย่างไร?**
ลบแอป แล้วลบ <code>~/Library/Containers/com.donghuazhu.FileExplorer8/</code> เพื่อล้างการตั้งค่า สถานะเซสชัน และข้อมูลปลายทางการเชื่อมต่อเซิร์ฟเวอร์ (แอปใน sandbox เก็บข้อมูลไว้ในคอนเทนเนอร์นี้ ไม่ได้อยู่ในตำแหน่งที่ใช้ร่วมกันของระบบ) รหัสผ่าน SSH อยู่ในพวงกุญแจและจะถูกลบไปพร้อมกับการเชื่อมต่อนั้น
