FileExplorer8 не собирает, не передаёт и не раскрывает данные пользователей. Нет учётных записей, аналитики, рекламных SDK и отчётов о сбоях. Всё, что вы видите в приложении, остаётся на вашем Mac.

1. Что мы не собираем

Ничего из перечисленного не собирается — ни одного пункта:

  • Ваши файлы и папки (содержимое, имена, размеры, даты изменения)
  • История просмотров и поиска, содержимое буфера обмена
  • Адреса серверов, учётные записи, пароли и приватные ключи, к которым вы подключаетесь
  • Идентификаторы устройства (серийный номер, аппаратный UUID, рекламный идентификатор)
  • Статистика использования, журналы сбоев, данные о производительности
  • Ваше местоположение, контакты, календарь, медиатека, микрофон, камера, содержимое экрана

В приложении нет ни одного сетевого запроса для отправки данных. Кроме SSH/SFTP-подключений, которые вы запускаете сами, приложение не отправляет ни одного байта на какой-либо сервер.

2. Где хранятся данные

Все настройки и учётные данные существуют только на этом Mac, в трёх местах:

РасположениеЧто хранитсяЗащита
Контейнер песочницы
~/Library/Containers/com.donghuazhu.FileExplorer8/		Настройки, состояние сеанса (положение окна, пути разделов), закладки быстрого доступаВнутри контейнера App Sandbox, доступно только этому приложению
Там же, servers.jsonКонечные точки серверов SSH (хост, порт, имя пользователя, отображаемое имя)AES-256-GCM (swift-crypto)
Связка ключей системыПароли SSH и парольные фразы приватных ключейЗащищены связкой ключей macOS

Пароли никогда не попадают в файл. В servers.json только конечные точки, без секретов. Пароли и парольные фразы хранятся в связке ключей и удаляются вместе со своим подключением.

Чтобы не было неясностей: ключ шифрования servers.json поставляется вместе с приложением (вкомпилирован в двоичный файл — не лежит отдельно на диске и не хранится в связке ключей). Это шифрование лишь мешает читать конечные точки между делом; оно не является защитой от локального злоумышленника, ведь тот, кто может читать ваш диск, прочитает и сам двоичный файл приложения. То, что действительно надо скрывать — пароли и парольные фразы — хранится только в связке ключей.

Файлы приватных ключей остаются там, где вы их положили. Приложение сохраняет лишь закладку для чтения; оно никогда их не копирует и не перемещает.

3. Доступ в сеть

У приложения ровно одна сетевая возможность: клиент SSH / SFTP.

  • Подключение возникает только после того, как вы добавите сервер и нажмёте «подключиться», и ведёт к адресу, который вы ввели
  • Оно служит для просмотра и передачи файлов по SSH (подсистема SFTP)
  • Ключи хоста проверяются по образцу known_hosts; при изменении отпечатка приложение просит подтверждение
  • Передаваемые данные шифруются самим SSH (OpenSSL в составе libssh2)

Мы не обслуживаем никаких серверов, нет ни ретрансляции, ни облачной синхронизации. Ваши файлы никогда не проходят через нас.

Приложение не проверяет обновления, не загружает удалённую рекламу и не обращается к сторонним API.

4. Системные разрешения

Приложение работает в App Sandbox и читает или записывает только в пределах выданных вами разрешений:

РазрешениеНазначениеКогда появляется
Файлы, выбранные пользователемПросмотр и действия в указанных вами папкахСистемный запрос при первом входе в папку вне песочницы
Папки Загрузки / Документы / Музыка / Изображения / ФильмыДоступ к этим стандартным местам без запросовДоступно сразу после установки
Доступ в сеть (исходящий)Подключение к добавленным вами серверам SSHТолько при нажатии «подключиться»

Таблица один к одному соответствует разрешениям песочницы в пакете приложения (app-sandbox, files.user-selected, files.downloads, assets.music / assets.pictures / assets.movies, network.client). Сверх этого ничего не запрашивается.

Приложение не запрашивает: контакты, календарь, напоминания, медиатеку, камеру, микрофон, запись экрана, полный доступ к диску и универсальный доступ. Если вы видите FileExplorer8 в каком-либо из этих пунктов в «Системных настройках › Конфиденциальность и безопасность», это не от нашего приложения.

Выдать и отозвать доступ к папкам можно в «Системных настройках › Конфиденциальность и безопасность › Файлы и папки».

5. Контрольные суммы

Приложение считает контрольные суммы (SHA-256 / SHA-512 / SHA-1 / MD5 / BLAKE3 / CRC32 / CRC64), чтобы проверять целостность файлов.

Эта функция читает только явно выбранные вами файлы, вычисляет дайджест в памяти и показывает его. Ничего не сохраняется и не отправляется. Дайджесты не покидают ваш Mac и не попадают в журналы.

У нас нет никаких ваших данных, поэтому нет и процедуры «запросить удаление у нас» — как нет и учётной записи, которую можно закрыть: у приложения нет учётных записей.

7. Сторонние компоненты

В приложении ровно две зависимости с открытым кодом:

В приложении нет рекламных SDK, SDK аналитики, сбора сбоев и социального входа.

8. Конфиденциальность детей

Приложение не собирает сведения ни от детей, ни от кого-либо ещё. Возрастной рейтинг в App Store — 4+.

9. Изменения политики

При изменении политики обновляется дата «Последнее обновление» вверху страницы, а изменение выходит с новой версией. Поскольку приложение не собирает данные, существенные изменения маловероятны.

English summary (for App Review reference)

FileExplorer8 does not collect, transmit, or share any user data.

  • No analytics, no ads, no crash reporting, no accounts.
  • All settings and credentials stay on the user's Mac. Passwords live in the macOS Keychain; server endpoints in a local file encrypted with AES-256-GCM (the key ships inside the app, so this obfuscates endpoints rather than protecting against local attackers).
  • The only network capability is an SSH/SFTP client that connects only to servers the user adds. We operate no servers and receive nothing.
  • The app runs in the App Sandbox and requests only user-selected file access, standard folders (Downloads / Documents / Music / Pictures / Movies), and outbound network access.
  • Two open-source dependencies: SwiftSFTP (embedded libssh2 + OpenSSL) and Apple's swift-crypto; both run fully locally with no telemetry.
