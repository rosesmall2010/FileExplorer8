FileExplorer8 はユーザーデータを収集、送信、共有しません。アカウントも統計も広告 SDK もクラッシュ報告もありません。アプリ内で扱うファイルはすべてお使いの Mac に留まります。

1. 収集しないもの

次のデータはひとつも収集しません：

  • ファイルとフォルダ（内容、名前、サイズ、更新日時）
  • 閲覧履歴、検索履歴、クリップボードの内容
  • 接続先のサーバーアドレス、アカウント、パスワード、秘密鍵
  • デバイス識別子（シリアル番号、ハードウェア UUID、広告識別子）
  • 利用統計、クラッシュログ、性能データ
  • 位置情報、連絡先、カレンダー、写真ライブラリ、マイク、カメラ、画面の内容

データ送信のためのネットワーク要求はアプリ内に一切ありません。ご自身で開始した SSH/SFTP 接続を除き、アプリはいかなるサーバーにも 1 バイトも送信しません。

2. データの保存場所

設定と認証情報はすべてこの Mac の上だけに、次の 3 か所に保存されます：

場所保存内容保護方法
アプリのサンドボックスコンテナ
~/Library/Containers/com.donghuazhu.FileExplorer8/		環境設定、セッション状態（ウィンドウ位置、各ペインのパスなど）、クイックアクセスのブックマークApp Sandbox コンテナ内。本アプリのみアクセス可能
同上、servers.jsonSSH サーバーのエンドポイント（ホスト、ポート、ユーザー名、表示名）AES-256-GCM で暗号化（swift-crypto）
システムキーチェーンSSH のパスワード、秘密鍵のパスフレーズmacOS のキーチェーンで保護

パスワードがファイルに入ることはありません。 servers.json にあるのはエンドポイント情報だけで秘密は含みません。パスワードとパスフレーズはシステムキーチェーンに保存され、接続を削除すると一緒に削除されます。

補足します。servers.json の暗号鍵はアプリと一緒に配布されます（バイナリに組み込まれ、別ファイルとしてもキーチェーンにも保存されません）。この暗号化はエンドポイント情報を気軽に覗かれないようにするためのもので、ローカルの攻撃者に対する保護にはなりません。ディスクを読める人はアプリ本体も読めるからです。本当に秘匿すべきもの（パスワード、パスフレーズ）は常にキーチェーンにのみ存在します。

秘密鍵ファイルそのものはあなたが置いた場所に留まります。アプリは読み取り用のファイルブックマークを保存するだけで、コピーも移動もしません。

3. ネットワークアクセス

アプリのネットワーク機能はSSH / SFTP クライアントの 1 つだけです。

  • ご自身でサーバーを追加し接続をクリックしたときにだけ接続し、接続先は入力したアドレスです
  • 用途はファイルの閲覧と転送で、プロトコルは SSH（SFTP サブシステム）です
  • ホスト鍵は known_hosts 方式で検証し、指紋が変わると確認を求めます
  • 転送内容は SSH 自体の暗号化（libssh2 に組み込まれた OpenSSL）で保護されます

当社はサーバーを運用していません。中継もクラウド同期もありません。あなたのファイルが当社を経由することはありません。

アプリはアップデート確認も、リモート広告の読み込みも、第三者の API 呼び出しも行いません。

4. システム権限

アプリは App Sandbox を有効にし、許可された範囲内でのみファイルを読み書きします：

権限用途表示されるタイミング
ユーザが選択したファイル指定したフォルダの閲覧と操作サンドボックス外のフォルダに初めて入るときにシステムが確認
ダウンロード／書類／ミュージック／ピクチャ／ムービー確認なしでこれらの標準的な場所にアクセスインストール直後から利用可能
ネットワークアクセス（外向き）ご自身で追加した SSH サーバーへの接続接続をクリックしたときのみ

上表はアプリバンドル内のサンドボックス権限と 1 対 1 で対応します（app-sandbox、files.user-selected、files.downloads、assets.music / assets.pictures / assets.movies、network.client）。余分な権限は要求していません。

アプリは次を要求しません：連絡先、カレンダー、リマインダー、写真ライブラリ、カメラ、マイク、画面収録、フルディスクアクセス、アクセシビリティ。システム設定 › プライバシーとセキュリティ のこれらの項目に FileExplorer8 が表示されていても、本アプリが要求したものではありません。

許可したフォルダは、システム設定 › プライバシーとセキュリティ › ファイルとフォルダ でいつでも取り消せます。

5. チェックサム機能

アプリはファイルの整合性確認のためにチェックサム（SHA-256 / SHA-512 / SHA-1 / MD5 / BLAKE3 / CRC32 / CRC64）を計算できます。

この機能は明示的に選択したファイルだけを読み取り、メモリ上でダイジェストを計算して表示します。保存も送信もしません。ダイジェストが Mac の外に出ることも、ログに残ることもありません。

6. データの削除

削除したいもの方法
特定の SSH 接続のパスワードアプリ内でその接続を削除すると、キーチェーン内のパスワードとパスフレーズも削除されます
すべての環境設定とセッションアプリ内の「リセット」、または ~/Library/Containers/com.donghuazhu.FileExplorer8/ を削除
すべてのデータアプリをアンインストールし、上記のフォルダを削除

当社はあなたに関するデータを一切持っていないため、「当社に削除を申請する」手続きはありません。アカウントも存在しないため、退会も不要です。

7. 第三者コンポーネント

アプリに含まれるオープンソースの依存は 2 つだけです：

コンポーネント用途説明
SwiftSFTPSSH / SFTP プロトコルの実装libssh2 と OpenSSL のソースを内包。完全にローカルで動作し、統計や送信のコードを含みません
swift-crypto暗号プリミティブ（Apple 製）AES-256-GCM、SHA-2、HMAC などの標準アルゴリズム。ローカル設定の暗号化、SSH ホスト指紋の検証、チェックサム計算に使用。すべてローカル演算でネットワークを使いません

アプリ内に広告 SDK、統計 SDK、クラッシュ収集 SDK、ソーシャルログイン SDK はありません。

8. 子どものプライバシー

本アプリは子どもからも、誰からも情報を収集しません。App Store の年齢制限は 4+ です。

9. ポリシーの変更

本ポリシーを変更する場合は、ページ上部の「最終更新」日を更新し、新しいバージョンとともに公開します。データを収集しないため、実質的な変更はほとんどない見込みです。

English summary (for App Review reference)

FileExplorer8 does not collect, transmit, or share any user data.

  • No analytics, no ads, no crash reporting, no accounts.
  • All settings and credentials stay on the user's Mac. Passwords live in the macOS Keychain; server endpoints in a local file encrypted with AES-256-GCM (the key ships inside the app, so this obfuscates endpoints rather than protecting against local attackers).
  • The only network capability is an SSH/SFTP client that connects only to servers the user adds. We operate no servers and receive nothing.
  • The app runs in the App Sandbox and requests only user-selected file access, standard folders (Downloads / Documents / Music / Pictures / Movies), and outbound network access.
  • Two open-source dependencies: SwiftSFTP (embedded libssh2 + OpenSSL) and Apple's swift-crypto; both run fully locally with no telemetry.
