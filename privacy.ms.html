FileExplorer8 tidak mengumpul, menghantar atau berkongsi sebarang data pengguna. Tiada akaun, tiada analitik, tiada SDK iklan, tiada laporan ranap. Semua yang anda lihat dalam aplikasi kekal pada Mac anda.

1. Apa yang tidak kami kumpul

Tiada satu pun daripada yang berikut dikumpul — tidak satu butiran:

  • Fail dan folder anda (kandungan, nama, saiz, tarikh ubah suai)
  • Sejarah pelayaran dan carian, kandungan papan keratan
  • Alamat pelayan, akaun, kata laluan dan kunci peribadi yang anda sambungi
  • Pengecam peranti (nombor sirí, UUID perkakasan, pengecam pengiklanan)
  • Statistik penggunaan, log ranap, data prestasi
  • Lokasi, kenalan, kalendar, pustaka foto, mikrofon, kamera, kandungan skrin anda

Tiada satu pun permintaan rangkaian dalam aplikasi untuk menghantar data. Selain sambungan SSH/SFTP yang anda mulakan sendiri, aplikasi tidak menghantar satu bait pun ke mana-mana pelayan.

2. Di mana data disimpan

Semua tetapan dan kelayakan hanya wujud pada Mac ini, di tiga tempat:

Kata laluan tidak pernah masuk ke fail. servers.json hanya mengandungi titik sambungan, tanpa rahsia. Kata laluan dan frasa laluan berada dalam Keychain dan terpadam bersama sambungannya.

Untuk jelas: kunci penyulitan servers.json diedarkan bersama aplikasi (dikompil ke dalam binari — tidak ditulis berasingan ke cakera, juga tidak dalam Keychain). Penyulitan ini hanya menghalang titik sambungan dibaca sewenang-wenangnya; ia bukan perlindungan terhadap penyerang setempat, kerana sesiapa yang boleh membaca cakera anda juga boleh membaca binari aplikasinya. Yang benar-benar perlu dirahsiakan — kata laluan dan frasa laluan — hanya berada dalam Keychain.

Fail kunci peribadi anda kekal di tempat anda meletakkannya. Aplikasi hanya menyimpan penanda baca; ia tidak pernah menyalin atau memindahkannya.

3. Akses rangkaian

Aplikasi mempunyai tepat satu keupayaan rangkaian: klien SSH / SFTP.

  • Sambungan hanya dibuat selepas anda menambah pelayan dan menekan sambung, menuju alamat yang anda masukkan
  • Ia digunakan untuk menjelajah dan memindahkan fail melalui SSH (subsistem SFTP)
  • Kunci hos disahkan secara known_hosts; cap jari yang berubah akan meminta pengesahan anda
  • Data yang dipindahkan disulitkan oleh SSH itu sendiri (OpenSSL seperti terbenam dalam libssh2)

Kami tidak mengendalikan sebarang pelayan dan tiada geganti atau penyegerakan awan. Fail anda tidak pernah melalui kami.

Aplikasi tidak menyemak kemas kini, tidak memuatkan iklan jauh, dan tidak memanggil mana-mana API pihak ketiga.

4. Kebenaran sistem

Aplikasi berjalan dalam App Sandbox dan hanya membaca atau menulis dalam lingkungan yang anda berikan:

Jadual di atas sepadan satu-satu dengan kebenaran sandbox dalam pek aplikasi (app-sandbox, files.user-selected, files.downloads, assets.music / assets.pictures / assets.movies, network.client). Tiada yang diminta lebih.

Aplikasi tidak meminta: kenalan, kalendar, peringatan, pustaka foto, kamera, mikrofon, rakaman skrin, akses seluruh cakera atau kebolehcapaian. Jika anda melihat FileExplorer8 di bawah mana-mana butiran itu dalam Tetapan Sistem › Privasi & Keselamatan, ia bukan daripada aplikasi ini.

Anda boleh menarik balik folder yang telah diberikan pada bila-bila masa dalam Tetapan Sistem › Privasi & Keselamatan › Fail dan Folder.

5. Jumlah semak

Aplikasi boleh mengira jumlah semak (SHA-256 / SHA-512 / SHA-1 / MD5 / BLAKE3 / CRC32 / CRC64) untuk menyemak keutuhan fail.

Ciri ini hanya membaca fail yang anda pilih secara jelas, mengira ringkasan dalam memori dan memaparkannya. Tiada disimpan, tiada dihantar. Ringkasan tidak pernah keluar dari Mac anda dan tidak masuk ke mana-mana log.

7. Komponen pihak ketiga

Aplikasi hanya mengandungi dua tanggungan sumber terbuka:

KomponenTujuanNota
SwiftSFTPPelaksanaan protokol SSH / SFTPMembenamkan sumber libssh2 dan OpenSSL; berjalan sepenuhnya setempat, tanpa kod analitik atau penghantaran
swift-cryptoPrimitif kriptografi (daripada Apple)AES-256-GCM, SHA-2, HMAC dan algoritma piawai lain; digunakan untuk penyulitan tetapan setempat, pengesahan cap jari hos SSH dan jumlah semak. Sepenuhnya setempat, tidak pernah ke rangkaian

Tiada SDK iklan, SDK analitik, SDK pengumpul ranap atau SDK log masuk sosial dalam aplikasi.

8. Privasi kanak-kanak

Aplikasi ini tidak mengumpul maklumat daripada kanak-kanak mahupun daripada sesiapa. Penarafan umur di App Store ialah 4+.

9. Perubahan dasar

Jika dasar ini berubah, tarikh “Kemas kini terakhir” di atas halaman akan disemak dan perubahan itu menyertai versi baharu. Oleh sebab aplikasi tidak mengumpul data, perubahan besar tidak dijangka.

English summary (for App Review reference)

FileExplorer8 does not collect, transmit, or share any user data.

  • No analytics, no ads, no crash reporting, no accounts.
  • All settings and credentials stay on the user's Mac. Passwords live in the macOS Keychain; server endpoints in a local file encrypted with AES-256-GCM (the key ships inside the app, so this obfuscates endpoints rather than protecting against local attackers).
  • The only network capability is an SSH/SFTP client that connects only to servers the user adds. We operate no servers and receive nothing.
  • The app runs in the App Sandbox and requests only user-selected file access, standard folders (Downloads / Documents / Music / Pictures / Movies), and outbound network access.
  • Two open-source dependencies: SwiftSFTP (embedded libssh2 + OpenSSL) and Apple's swift-crypto; both run fully locally with no telemetry.
